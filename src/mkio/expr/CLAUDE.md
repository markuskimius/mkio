# mkio.expr — the expression language

One grammar shared with the JS implementation (`../client/mkio-expr.mjs`, served at `/mkio-expr.js`), pinned by the fixtures in `tests/expr_cases.json` that both suites run (`tests/test_expr.py`, and `tests/run_expr_cases.mjs` under node via `tests/test_expr_js.py`). Syntax and precedence: the README's Expression Language section, whose function tables are generated (`scripts/gen_expr_docs.py`; `tests/test_expr_docs.py` checks they are in sync).

## Semantics

strict `==` (no coercion); falsy = `NULL FALSE 0 '' [] {}`; one number type, integral values print without a fraction; `//` = `FLOOR(a/b)`, `%` takes the divisor's sign; `&& || ??` and `IF CASE TRY LET` short-circuit; `+` only on number+number or string+string (host types via `register_type`); missing map keys / out-of-range indexes / indexing NULL → NULL; an unknown *root* name is an error in a strict `Env` (mkio's default) and NULL in a lenient one; `__*`, `constructor`, `prototype` keys are blocked. Templates: `compile_template("a ${expr} b")` — a template that is exactly one `${..}` returns the raw value, otherwise a string; `$${` escapes. Standard libraries (all on by default) live in `_lib_core/math/string/format/time/collection.py`; the README's generated tables list every function (`scripts/gen_expr_docs.py`, sync checked by tests). Time unit is seconds since the epoch; `EPOCH` parses refs and ISO-8601; strftime subset `%Y %m %d %H %M %S %f %z`; tz `UTC`/`local`/`±HH:MM`. `ROUND`/`NUM` round half away from zero on the decimal representation (`ROUND(2.675, 2)` = 2.68). Extension (README "Extending the language"): `register_function` (lazy ones get `(ctx, *Arg)` thunks with `.value()`, `.eval(scope)`, `.name`), `register_library`, `register_type` (`concat` lets the type survive mixed `${}` templates; otherwise `to_string`), `Env(libraries=[..], strict=)`. Analysis: `field_refs`, `function_refs`, `numeric_fields`. Parsing is env-free; `compile` validates function names against the env, so unknown functions fail at config load. mkui registers its own library/type through these hooks.

## Language 2 (additive over 1)

`and`/`or`/`not`/`in`/`not in` are contextual words, never reserved — operators only where no name could stand (`_Parser.word`/`at_word`; `not - 1` still subtracts), building the `&&`/`||`/`!` nodes plus `Binary("in")`; `not` sits between `and` and comparisons, and NOT is refused as a function name. `500ms 2s 1.5m 1h 1d` are DURATION tokens evaluating to seconds (`ms` divides, for identical doubles in JS). `COUNT`, and `fn` forms of `SUM`/`AVG`/`MIN`/`MAX`. Host tools, Python only: `parse_prefix(text, pos, stop=)` (lenient tokenizer: an ERROR token matters only if reached), `field_paths`/`check_fields(ast, schema)`, `register_library(default=False)` + `Env(extra=)`. A language change = both implementations + `expr_cases.json` + `LANGUAGE_VERSION`; mkui vendors the JS file and the cases verbatim, and the `_mkio` check compares `expr` exactly.

## Files

`_lexer.py` tokens · `_parser.py` recursive descent (precedence table in its docstring) · `_ast.py` frozen dataclasses with `pos` · `_eval.py` closures over `Scope` · `_env.py` registries and `Env` · `_analysis.py` refs, numeric fields, field paths · `_template.py` · `_values.py` equality, comparison, coercion · `_lib_*.py` the standard libraries.
